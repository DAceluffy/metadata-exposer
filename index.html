The Private, In-Browser Metadata Inspector & EXIF Stripper

Every digital photo, audio file, and document contains hidden metadata that reveals sensitive personal data—from exact GPS home coordinates and camera hardware serials to author identities. EXPOSER is built to expose and sanitize this data 100% client-side with zero tracking.

Image EXIF & GPS Radar

Extract Exchangeable Image File Format (EXIF), IPTC, and XMP tags. Inspect camera model, lens optics, focal length, ISO, exposure time, and map exact physical GPS coordinates on an interactive radar pin.

Privacy EXIF Sanitizer

Strip GPS coordinates, device serial numbers, and software signatures with a single click. Uses an isolated HTML5 canvas buffer to re-encode clean, lightweight images before sharing online.

Audio ID3 & Video Specs

Inspect MP3, WAV, and FLAC files for title, artist, album, year, and embedded cover art. Analyze video files (MP4, WebM) for exact resolution, aspect ratios, and duration.

PDF & Code Integrity

Audit document author, creator software, modification timestamps, and page counts. Generate instant SHA-256 and SHA-1 cryptographic checksums using native Web Crypto APIs.

Frequently Asked Questions

How can I view EXIF metadata online without uploading files to a server?

EXPOSER executes 100% client-side inside your web browser. When you select or drag a file, the browser's JavaScript engine reads the binary byte stream directly into local memory. Your files are never uploaded to any remote server or cloud, ensuring total confidentiality.

Can photo metadata reveal where a picture was taken?

Yes. Smartphones (iPhones, Android devices) and digital cameras record latitude, longitude, and altitude in EXIF tags. If uploaded without sanitization, anyone can extract these coordinates and pinpoint your home, workplace, or travel locations. EXPOSER identifies these coordinates and plots them on an interactive radar map.

How do I strip or remove metadata from images for free?

Switch to the Privacy Sanitizer tab, drop your photo, and click "Strip Metadata & Download". The tool renders your image onto an isolated in-browser canvas buffer and re-exports it without any EXIF, GPS, or camera hardware serial numbers.

What file formats does EXPOSER support?

EXPOSER supports all major multimedia and document formats: Images (JPEG, PNG, WebP, GIF, TIFF, SVG, HEIC), Audio (MP3, WAV, FLAC, OGG, M4A), Video (MP4, WebM, MOV), Documents (PDF, TXT, JSON, CSV), and Web URLs / HTML <head> tags (OpenGraph, Twitter Cards, Schema.org).
